SUMMA Contributions

We welcome community contributions in the forms of bug reports or pull requests. For bug reports, head over to the Issues section on the SUMMA GitHub page. Please look around for existing issues and add to those when appropriate before opening a new one.

For pull requests, please note that you will not be able to contribute to the main SUMMA repo directly. Using git is a requirement for contributions. For more information about working with the SUMMA code, please see the following documents:

  • SUMMA and Git
  • Git Workflow for SUMMA
  • SUMMA Coding Conventions
  • Modularity in SUMMA
